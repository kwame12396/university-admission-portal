============================================================
  University of Botswana — Online Admission System
  CSI315 Web Technology & Applications
  SETUP INSTRUCTIONS
============================================================

REQUIREMENTS
------------
- XAMPP / WAMP / LAMP (PHP 8.0+ & MySQL 5.7+ / MariaDB)
- phpMyAdmin
- Apache with mod_rewrite enabled

STEP 1: DATABASE SETUP
----------------------
1. Open phpMyAdmin (http://localhost/phpmyadmin)
2. Make sure "db_mat01296" already exists (your school DB)
3. Click on "db_mat01296" in the left panel to select it
4. Click the "SQL" tab
5. Paste the contents of:  db/ub_admission.sql
6. Click "Go" to run it — this creates all tables inside db_mat01296

STEP 2: CONFIGURE DATABASE CONNECTION
--------------------------------------
Open config.php and update these values to match your setup:

    define('DB_HOST', 'localhost');    // usually localhost
    define('DB_USER', 'root');         // your MySQL username
    define('DB_PASS', '');             // your MySQL password
    define('DB_NAME', 'ub_admission'); // leave as-is

STEP 3: PLACE FILES ON SERVER
------------------------------
Copy the entire "ub_admission" folder to your web server root:
    XAMPP:  C:/xampp/htdocs/ub_admission/
    WAMP:   C:/wamp64/www/ub_admission/
    Linux:  /var/www/html/ub_admission/

STEP 4: UPDATE SITE_URL
------------------------
In config.php, update SITE_URL to your server address:
    define('SITE_URL', 'http://localhost/ub_admission');

STEP 5: UPLOADS FOLDER PERMISSIONS (Linux/Mac)
-----------------------------------------------
chmod 755 uploads/

STEP 6: ACCESS THE SYSTEM
---------------------------
Student Portal:  http://localhost/ub_admission/
Admin Portal:    http://localhost/ub_admission/admin/login.php

DEFAULT ADMIN CREDENTIALS:
    Username:  admin
    Password:  Admin@UB2024!
    (Change this immediately after first login!)

============================================================
  PASSWORD POLICY
============================================================
All student passwords must meet:
  ✔ Minimum 8 characters
  ✔ At least 1 uppercase letter (A-Z)
  ✔ At least 1 lowercase letter (a-z)
  ✔ At least 1 number (0-9)
  ✔ At least 1 special character (!@#$%^&* etc.)

Enforced both client-side (JS) and server-side (PHP).

============================================================
  BGCSE POINT SYSTEM
============================================================
  A* = 8 points
  A  = 7 points
  B  = 6 points
  C  = 5 points
  D  = 4 points
  E  = 3 points
  U  = 0 points

Ranking generated automatically at: admin/ranking.php
Default programme for ranking: BSc General (others selectable)
Sorted in descending order by total points.
Ties broken by earliest submission date.
